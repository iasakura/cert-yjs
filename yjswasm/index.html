Yjs and Cert-Yjs editing together

One shared text, two replicas. The left one is Yjs, the JavaScript library. The right one is Cert-Yjs, a CRDT written in Go after Yjs and verified in Rocq, compiled to WebAssembly. They exchange Yjs's own update format over a simulated network. Type in either box. To see a merge, switch the network off, edit both sides, and switch it back on.

Yjs runs here with garbage collection off: Cert-Yjs cannot yet read an update in which Yjs has garbage-collected deleted text, which Yjs does by default. The core of Cert-Yjs is verified; the encoding of updates and the WebAssembly binding are not.
